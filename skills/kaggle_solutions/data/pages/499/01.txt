TL; DR

We used three groups of models in our solution, named CLS group (gray boxes), SEG group (blue boxes) and 3D group (yellow boxes). CLS group is used to classify whether the prediction of a slice should be empty or not. SEG group and 3D group are used to do segmentation for slices that should be predicted.

notebook

Our submission notebook is for referencing only. Model weights will not be released.

github

Here is my github repo for this solution.

1. CLS group
1.1 Data

Models were trained with the whole dataset, instead of folds.

Some models were trained without wrong annotated cases (mentioned in discussion).

1.2 Model

4 unets, with efficientnet b4, b5, b6, b7 backbones.

1.3 Training

Public mmsegmentation pipeline.

1.4 Usage

We computed prediction result of each slice of test data, using 0.6 threshold to binarize sigmoid probabilities. If the number of positive pixels if larger than 12, the slice is defined as "positive slice" (#pixels check arrow). Otherwise, the slice is defined as negative, which will skip further computation, and generate zero masks only.

2. SEG group
2.1 Data

Efficientnet-Unet models were trained with annotated slices (green arrow) in the whole dataset, which means, slices that have no annotation will not used in this step.

ConvNeXt-UPernet models were trained with all slices in the whole dataset, except 5 slices following the end point (orange arrow) of large-bowel and small-bowel. We believe these slices' annotation will introduce ambiguous supervision.

Some models were trained without wrong annotated cases (mentioned in discussion).

2.2 Model

5 unets, with b4, two b5, b6 and b7 backbones.

2 upernet, with convnext-base and convnext-small backbones.

2.3 Training

Public mmsegmentation pipeline.

2.4 Usage

We computed logits prediction result of each positive slice of test data.

3. 3D group
3.1 Data

Public MONAI pipeline data preprocessing

3.2 Model

3 SegResNets, with init_filters = 12, 20, 32, PRELU activation and batch norm.

3.3 Training

Public MONAI pipeline training.

3.4 Usage

We computed logits prediction result of each volume of test data. The 3D logits and 2.5D logits were merged using 0.4/0.6 weights, then binarized using threshold 0.4.

4. Hyperparameters

All hyperparameters will be listed in config files. The dataset of all config files will be released soon.

In short, for CLS group and SEG group, we used dice-ce, ce, dice loss for different models. We used elastic transform, grid distortion and optical distortion, with default flip, rotation in data augmentations.

For 3D groups, we used default trained pipeline as public MONAI dataset in first stage training. And we used cosine annealing, 1e-4->1e-6 learning rate, 20 epochs in second stage training.

And also thanks to other competitors that inovated us by their previous solutions: [1], [2], [3], from which our classification-segmentation two-stage pipeline and training tricks comes.
