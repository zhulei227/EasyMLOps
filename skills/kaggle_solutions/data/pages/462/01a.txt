Google Brain - Ventilator Pressure Prediction

Solution Writeup · 1st place · Nov 13, 2021

We have uploaded a big chunk of our code required to reproduce our solution as notebooks on Kaggle.

LSTM CNN transformer The code required to run a single fold of our LSTM + CNN Transformer model. Running multiple folds of this and taking a median ensemble should result in a significant boost of LB scores.

PID Controller Matching The code & intuition behind the PID controller matching. The current code is a preliminary version that still introduces some errors. Newer versions will be uploaded shortly.

Github repos:

PID Controller Matching
LSTM+CNN Transformer
LSTM on Raw data

Pretrained models:

https://www.kaggle.com/shujun717/googlebrainventilator1stshujun

In case there are any questions, feel free to leave a comment on the corresponding notebook or here!

Our LSTM model will soon be uploaded as a notebook as well so that people can play around with that one too (I will update this topic once it is published). Moreover, I have started writing the blog post with a more elaborate explanation of our solution, I will make a new topic with a link once this is finished!
