 Second place in Kaggle contest 
 Les Bricoleurs: Dima Kamalov , Matt Wescott 

 ####Hardware / OS 

 M3.2XLarge instance on Amazon EC2

 8 virtual cpu 
 26 gb ram 
 Intel Xeon E5-2670 

 Ubuntu 12.04, 64 bit, Server Edition 

 ####Dependencies 

 numpy/scipy 
 pandas 
 scikit-learn 

 ####Installation Instructions (from fresh EC2 instance) 

 sudo apt-get update 
 sudo apt-get install git 
 sudo apt-get install python-pip python-dev build-essential libblas-dev liblapack-dev gfortran 
 sudo pip install virtualenv 
 git clone git@github.com:mattwescott/bird-recognition.git 
 cd bird-recognition 
 Get the data 
 Edit paths in SETTINGS.json to point to the data 
 virtualenv venv 
 source venv/bin/activate 
 pip install -r requirements.txt 

 ####Generate Kaggle submission 

 python create_submission.py (~4 hours runtime)
